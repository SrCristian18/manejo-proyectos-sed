# Gestor financiero de proyectos SED
Software para el seguimiento de presupuestos y metas en educación superior (SED Cartagena)

## Stack Tecnológico
* **Backend:** Java 21 - Spring Boot 4.1.1
* **Base de Datos:** MySQL 8.x
* **Frontend:** Thymeleaf + Bootstrap
* **Gestor de Dependencias:** Maven
* **Despliegue:** Docker

* **Metadatos Spring boot**
* Group: com.sed
* Artifact: gestor.proyectos
* Package name: com.sed.gestor.proyectos
